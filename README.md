# arca-moulds

Salvador Workshop's 3D [Code-CAD](https://github.com/Irev-Dev/curated-code-cad) tools for generating casting mould designs.

## Usage

### `npm run moulds`

Build moulds around an STL model by running:

`npm run moulds --project="example1"`

The mould object must be named `model.stl` and placed in the appropriate directory in `input/` (in the above case, `input/example1`)
